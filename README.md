# AI-assisted UAV Locate-and-Supply Missions After Urban Floods

AAE5103 group project at The Hong Kong Polytechnic University.

This repository contains project code, Excel workbooks and supporting files for three parts:

1. Information acquisition: organising online rescue requests into structured demand records.
2. Task allocation: allocating relief supplies and scheduling UAV deliveries.
3. Route planning: planning obstacle-avoiding UAV routes in a simulated urban environment.

## Repository Structure

- part02_task_allocation/: Part 2 code, Excel workbooks and running instructions.
- part03_route_planning/: Part 3 route planning code and configuration files.

Each part includes its own documentation. Files for the remaining part will be added separately.
